### Figure 1 Tree Plot of subspecies present in East Africa.
Tree plot considering subspecies present in East Africa, the tree was made by clustering principal component analysis results, which was performed using ~6,000,000 WGS SNPs. Labels are coloured according to the subspecies. Newly sequenced Rwenzori mountains samples are represented with roman number labels I – VII and RW.
